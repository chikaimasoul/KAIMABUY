# CHIKAIMA 純露團購頁

純 HTML / CSS / JavaScript，可上傳 GitHub Pages；Google Apps Script 負責存進試算表及寄訂購明細。商品圖片未提供，採文字商品卡。LINE Pay 為掃碼付款與人工核帳，沒有串接自動扣款或金流查帳。

## 上線前要準備

1. 官方 LINE 已設定：https://lin.ee/SIBRj7v。
2. 已加入提供的 LINE Pay QR Code：assets/linepay.png。上線前請實際掃碼確認收款對象。
3. 宅配運費已設定 65 元，全家 60 元；仍需確認團購截止日、預計出貨時間與未成團退款安排。
4. 供應商確認純露可採宅配／超取的配送方式與溫度条件。頁面未宣稱一般超取可維持冷藏；若不適合常溫運送，先調整配送方式再上線。
5. 商品適用方式與標示：已依要求在「原始資料關鍵字」保留止血、抗病毒等原文，標示功效未核實。這些仍可能被判定為醫療宣稱；免責文字無法保證合規。未恢復洗鼻操作或治療感冒用法，未把孕嬰、蠶豆症適用視為已確認資訊。公開前請確認商品分類與可刊登的廣告內容。

## 建立 Google 試算表後台

1. 新建私人 Google 試算表。不要將試算表公開、不要放到 GitHub。
2. 在試算表選「擴充功能 → Apps Script」。把 `Code.gs` 全部貼入。
3. 到 Apps Script「專案設定 → 指令碼屬性」新增：

| 屬性 | 值 |
|---|---|
| SPREADSHEET_ID | 試算表網址 `/d/` 和 `/edit` 之間的字串 |
| SHIPPING_HOME | 65（省略時預設 65） |
| SHIPPING_FAMILY | 60（省略時預設 60） |

目前已按本次團購運費設定。

4. 編輯器選取 `setup`，手動執行一次並完成 Google 權限授權。
5. 選「部署 → 新增部署作業 → 網頁應用程式」。執行身分選自己，存取權限選任何人。複製 `/exec` 網址。若帳號政策不允許公開網頁應用程式，需要換可公開部署的帳號或另外建後台。
6. 修改 `config.js`：填入 `scriptUrl`。LINE 與運費已完成設定。
7. 如需 LINE Pay，把真實 QR Code 放在 `assets/linepay.png`，並將 `linePayQr` 設為 `assets/linepay.png`；未設定則關閉 LINE Pay 付款選項。

後台會建立「訂單」工作表，包含所有訂購人／收件人欄位、明細、金額、付款回報及確認信狀態。後台使用固定商品價格重新計價，不信任客戶端金額。修改價格或運費時，前台和後台需一起更新，並重新部署 Apps Script 的新版本。

## 放上 GitHub Pages

1. 建立 GitHub repository，把 `index.html`、`style.css`、`app.js`、`config.js` 上傳至根目錄。QR 圖片另外上傳至 `assets` 目錄。
2. Settings → Pages → Deploy from a branch → main / root → Save。
3. 等 GitHub 提供正式網址，再用手機與電腦試訂一筆。
4. `Code.gs` 是後台程式，不會因為上傳 GitHub 就開始執行；仍需完成上方 Apps Script 部署。

## 客人流程

選購 → 購物車 → 填收件資料 → 後台確認建單 → 寄訂購明細 → 顯示匯款帳號／QR Code → 客人付款 → 填實際金額和後五碼（LINE Pay 填交易編號）→ 儲存付款回報 → 自動嘗試複製回報 → 開啟官方 LINE → 客人貼上並送出。

瀏覽器若阻擋自動複製，可按「複製付款回報」或直接選取文字。網頁無法替客人自動送出 LINE 訊息。付款狀態只有「待付款」或「已回報，待核對」；主辦人確認入帳後自行在試算表更新，不會因填後五碼就顯示已付款。

## 上線驗收

- 各品項加減、移除與總價正確；手機無橫向溢出。
- 宅配要求郵遞區號／地址；全家要求店名。
- 空購物車、無效手機／Email、缺少設定無法正常結帳。
- 真實測試訂單只產生一筆；試算表手機、郵遞區號與後五碼保留開頭的 0。
- 確認客人 Email 收到訂購明細（包含垃圾信箱）。Google 寄信配額依帳號而異；超過配額或寄信失败會記錄「寄送失敗，請人工補寄」，訂單仍保留。
- 銀行及 LINE Pay 回報可記錄，官方 LINE 連結與 QR Code 正確。
- 泡澡露總瓶數自行彙整；本版不會自動達成成團、退款或通知。

公開後台未加登入或 CAPTCHA，適合小型團購，仍可能收到垃圾訂單；如流量增大可另加防濫用機制。請只讓必要的工作人員存取試算表，並依自己的政策刪除已不需保留的個資。本版不在瀏覽器儲存收件資料；頁面關閉後如需找回訂單，請透過官方 LINE。

本交付已做程式語法及模擬後台測試；因尚未提供部署網址與實際 Google 權限，未執行真實寄信、LINE Pay 或跨站送單驗證。付款前請先完成實際上線驗收。
